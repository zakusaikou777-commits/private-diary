日記帳 & 気になり帳 一式

【中身】
- index.html ……………………… 入口（タブで日記帳/気になり帳/暗室/音を切替）
- diary.html …………………… 日記帳本体
- kininari.html ……………… 気になり帳本体（クリップ取り込み対応）
- tasks.html …………………… タスク（期限・繰り返し・Googleカレンダー連携）
- image-streaming.html …… 暗室（イメージストリーミング）本体
- bgm.html ……………………… 音（作業用BGMランチャー・就寝用の音）
- autogenic.html …………… くつろぎ（自律訓練法の音声ガイド）
- audio/ ………………………… 就寝用の音（brown/pink/rain の各wav。合計約1.8MB）
- sync.js ……………………… 音・暗室の端末間同期（Googleドライブ経由）
- sw.js ………………………… オフライン動作・タスク通知用
- manifest.webmanifest …… PWA設定（ホーム画面に追加・共有メニュー対応）
- icon-192.png / icon-512.png / icon-512-maskable.png … アプリアイコン
- clipper.html ……………… Chrome拡張の説明＆ダウンロードページ
- kininari-clipper/ ……… Chrome拡張のフォルダ（そのまま読み込めます）

【1. サイトに置く（ホスティング）】
ZIPの中身を「まるごと同じフォルダ」に置き、https で公開してください。
（一部だけ置くと、暗室タブが開かない・ホーム画面に追加できない等になります）

  必須: index.html / diary.html / kininari.html / image-streaming.html /
        bgm.html / autogenic.html / tasks.html / audio/（フォルダごと） / sync.js / sw.js / manifest.webmanifest /
        icon-192.png / icon-512.png / icon-512-maskable.png
  任意: clipper.html（拡張の配布ページ。使わないなら不要）

- 開くときは index.html。
- file:// では動きません（ログイン・カレンダー・通知のため https 必須）。
- 無料の例: GitHub Pages、Netlify、Cloudflare Pages など。

【2. Chrome拡張（ニュースを気になり帳に保存）】
1) Chromeで chrome://extensions を開く
2) 右上「デベロッパーモード」をオン
3)「パッケージ化されていない拡張機能を読み込む」→ kininari-clipper フォルダを選択
4) ツールバーの「気」アイコン → ⚙ に、自分の kininari.html のURL（https）を入力
   例: https://yourname.github.io/app/kininari.html
5) 以降、ページで「気」アイコン → 保存
※ clipper.html をサイトに置けば、そのページからも拡張をダウンロードできます。

【3. Google連携（ドライブ/カレンダー）の事前設定】
アプリ内の ❓ ヘルプ画面に手順をまとめています（API有効化・スコープ・JavaScript生成元の登録など）。

【音（BGM）タブについて】
- YouTubeのBGMを毎回検索せずに呼び出すためのタブです。ジャンル検索 → 気に入った
  URLを登録 → 次回はタップだけ。お気に入り★と再生履歴が残ります。
- 他のタブに切り替えても鳴り続けます（アプリを開いている間）。
- ★重要: スマホで画面を消すとYouTubeは止まります。ブラウザ側の仕様で回避でき
  ません（iPhoneのSafariも同じ）。💡ボタンで消灯を防げますが電池を多く使います。
- 「就寝用の音」（ブラウンノイズ/ピンクノイズ/雨）は端末内の音です。再生は
  アプリの最上位（index.html）で行うので、他のタブに切り替えても、画面を
  消しても鳴り続けます。ロック画面からの再生・停止も使えます。
- Androidでは、YouTubeアプリの「共有」からこのアプリに送ると音タブに登録されます。

【タスクタブについて】
- 気になり帳が「書き留める場所」、タスクは「終わらせるもの」の置き場です。
- 「今日」「明日」「来週」で期限をすぐ決められます。期限切れは赤で強調され、
  一覧の先頭にまとまります。
- 繰り返し（毎日／平日／毎週／毎月）に対応。完了すると次回ぶんが自動で作られます。
  毎月は月末（31日など）を指定しても、短い月は末日に丸めたうえで、翌月は元の
  日付に戻ります。
- 📅 ボタンでGoogleカレンダーに登録できます。気になり帳と同じ設定を使うので、
  追加の設定は不要です。
- Googleタスクと双方向で同期できます（完了チェックも両方向で揃います）。
  事前にCloud Consoleで以下が必要です:
    1) Tasks API を有効化
       console.cloud.google.com/apis/library/tasks.googleapis.com
    2) OAuth同意画面のスコープに https://www.googleapis.com/auth/tasks を追加
    3) アプリの ☁ でクライアントIDの「保存」を押し直す（再ログインのため）
  ※ 時刻と繰り返しはこのアプリだけの情報です（Googleタスクの期限は日付のみ）。
  ※ 1週間以上前に完了したタスクは、Google側へ新規送信しません。
- 気になり帳のメモの「タスクにする」を押すと、こちらに送られます。元のメモは
  残るので、記録は気になり帳、実行はタスク、と使い分けられます。

【くつろぎ（自律訓練）タブについて】
★これは治療ではありません。運転や機械操作の予定があるときは行わないでください。
  通院中の方、心臓・呼吸器の病気、糖尿病、強い気分の落ち込みや不安がある方は、
  始める前に主治医にご相談ください。

- 初めは「第1公式 — 重感」だけを2週間ほど続けるのが標準です。既定でそうなっています。
- 心臓（第3）・お腹（第5）の段階は不快感が出ることがあるため、既定では外して
  あります。使う場合は設定から有効にしてください。
- 最後の「消去動作」は省略できません。中断した場合も短縮版を必ず通ります。
  省くとだるさやぼんやりした感じが残ることがあります。
- 練習中は自動で画面が消えないようにします（終わると元に戻ります）。途中で
  画面が消えると読み上げが止まり、消去動作まで進めないためです。
- 練習中に腕のピクつきや涙などが出ることがあります（自律性発散）。多くは問題
  ありませんが、強く不快なときは中止してください。
- 声は「暗室」の設定を共有します。背景音は「音」タブの就寝用の音を使えます。
- 誘導文は「誘導文の編集」から自分で書き換えられます（文・沈黙の秒数・自分の段階の
  追加）。編集はこの端末に保存されるため、アプリのファイルを差し替えても消えません。
  JSONで書き出し／読み込みもでき、PC・スマホ間でも同期されます。
  ただし消去動作は削除できません（空にすると練習後にぼんやりしたまま終わるため）。

【暗室の読み上げの声】
- 声は「端末に入っているもの」から選びます（ブラウザの仕様で、アプリ側から
  声を配布することはできません）。
- 暗室の画面で、声の選択・高さ・速さを調整できます。設定はその端末だけに
  保存され、同期されません（入っている声が端末ごとに違うため）。
- もっと自然にしたい場合は、OS側で高品質な音声を追加してください。
    iPhone/iPad: 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語
    Windows: 設定 → 時刻と言語 → 音声認識 で音声を追加（Nanami が滑らか）
    Android/Chrome: 「Google 日本語」が入っていればそれが最も自然です
  追加後、暗室の画面を再読み込みすると一覧に出てきます。

【同期の仕組みについて（v19で修正）】
- 以前は「最終同期の時刻より後に作られたか」で新規項目を判定していました。
  この時刻はGoogleドライブのサーバー時刻で、比較相手は端末の時計だったため、
  端末の時計が遅れていると、追加したばかりの項目が消えることがありました。
- 現在は各項目に「同期済み」の印を付けて判定します。印が無いものは必ず残るので、
  時計のずれに影響されません。

【データの同期・バックアップ】
入口は画面上部の ☁ ひとつだけです（❓ヘルプの隣）。各アプリの中にあった
同期ボタンは、シェル経由で開いたときは表示されません。

- クライアントIDは4アプリ共通（shared:gd:cid）。設定は一度だけです。
- ☁ を開くと、日記帳・気になり帳・暗室・音の同期状態が一覧で見られます。
  「今すぐ全部同期」で4つまとめて実行します。
- Googleを使わない「まとめて書き出す／取り込む」も同じ画面にあります。
- 同期されるもの: 音＝登録/ジャンル/★/再生履歴、暗室＝練習の記録、
  日記帳と気になり帳＝従来どおり。
- 同期されないもの: 音量・夜間モード・表示の絞り込みなど端末ごとの設定。
- 再生中の曲が連動することはありません（データだけの同期です）。

【データについて】
すべて自分専用です。データは自分の端末に保存され、Google連携も自分のアカウント/自分のクライアントIDのみを使います。

【更新時の注意】
ファイルを差し替えたら、ブラウザで一度リロードしてください。Service Worker は
オンライン時つねに最新を取りに行く設定なので、通常はこれだけで新しい版になります。

【v22 での修正（v21 からの変更）】
データが消える不具合を中心に、重大11件・中30件を直しました。おもなものは次のとおりです。

■ データが消えなくなりました
- ☁の「今すぐ全部同期」を押すと、気になり帳のメモが全部消えることがありました。
  読み込みが終わる前の空の状態でDriveを上書きしていたためです（両方が空になりました）。
  送る中身は必ず「いま保存されている内容」から取るようにし、読めないときは中止します。
- 「同期済み」の印を、送信が成功する前に付けていました。オフラインや通信失敗のあとの
  同期で「同期済みなのにDriveに無い＝他端末で削除された」と誤判定し、まだ一度も送って
  いない項目を消していました。印を付けるのは送信できたあとだけにしました。
- 日記帳がロック中（暗号化を解除していない状態）でも、Driveを「空の平文」で上書きして
  いました。ロック中・読み込み失敗時は書き出しを止めます。
- 日記帳の同期が「読み込まずに全件上書き」だったため、片方の端末で書いた日記が
  もう片方の保存で消えていました。読み込んでからマージして書くようにし、削除も
  墓標で伝わるようにしました（消した日記が復活しなくなりました）。
- アップロード中に書いたメモが、完了時に巻き戻って消えていました。
- 気になり帳のフォルダ削除に墓標が無く、消したフォルダが復活していました。

■ 同期・連携
- タスクのGoogleタスク連携が10秒ごとに永久にループしていました。
- Googleタスクが100件を超えると紐付けが外れ、同じタスクが増殖していました（ページング対応）。
- Googleタスクアプリで消したタスクが、同じ同期のうちに作り直されていました。
- 「今すぐ全部同期」が0.5秒の決め打ちで、重いタブには命令が届いていませんでした。
  各タブの準備ができた合図を待ってから送るようにしました。
- 「まとめて取り込む」のあと、Driveの古い内容に上書きし返されていました。取り込み後は
  同期の記録を消し、自動同期をいったんOFFにします。

■ 安全・セキュリティ
- シェルが受け取るメッセージに送信元の確認が無く、外部サイトから任意のスクリプトを
  実行できる状態でした（Googleのトークンを読めてしまいます）。送信元の確認と
  エスケープを入れました。
- クリップのURLを検証せずにリンクにしていたため、javascript: が実行できました。

■ くつろぎ（自律訓練）
- 消去動作が飛ぶ経路が複数ありました（リロード、画面消灯、台本の不備での停止）。
  練習中の目印を残し、次に開いたときに気づいて消去動作を行えるようにしました
  （iPhoneで音が出せるよう、復帰時は1回タップしてから始めます）。
- 台本の取り込みで、壊れたJSONが保存されてアプリが起動しなくなることがありました。
- 「＋ 行を追加」が何も起きませんでした。編集は自動で保存されます。
- 練習の記録が上限で黙って消えることはありません。

■ 音
- YouTubeの共有リンク（watch?v=…&list=…）で、指定した動画ではなくプレイリストの
  先頭が鳴っていました。起動時に一瞬音が出ることもなくなりました。
- プレーヤーの準備前に押した再生が無視され、再生回数だけ増えていました。
- 保存できないとき（容量超過）に、その場は成功したように見えて翌日消えていました。

■ 日記帳
- 深夜0〜9時に新規作成すると前日の日付になっていました。
- 検索がHTMLのタグを対象にしていたため、装飾した文字が検索に掛かりませんでした。
- 一覧から別の日記を開くと、未保存の変更が警告なく消えていました。

■ Chrome拡張（v1.2.1）
- clipper.html が配っていたZIPが旧版(v1.0.1)のままでした。作り直し、ページに
  バージョンを表示するようにしました。
- 「保存を確認してから閉じる」機能が、実行環境の違いで常に働いていませんでした。
- 権限の確認が保存の途中に入っていて、初回の保存が消えることがありました。
  権限は⚙のボタンから明示的に許可する形にしました。
- 選択テキストが長すぎるとURLが壊れて保存できないのに「保存しました」と出ていました。

■ 開発用（.tools/）
- .tools/check.js …… 各HTMLの中のスクリプトをまとめて構文チェックします。
    node .tools/check.js *.html sync.js sw.js
- .tools/test-merge.js …… 同期の要になる関数（マージ・墓標・印の付け方）を検証します。
    node .tools/test-merge.js
- .tools/build-clipper.py …… 拡張のZIPを作り直して clipper.html に埋め直します。
    python3 .tools/build-clipper.py
  ※ 拡張を直したら必ず実行してください。忘れると配布ページが古い版を配ります。

【v23 での追加（日記帳）】

■ 画像を貼れるようになりました
- 貼り付け（⌘/Ctrl+V）・ドラッグして落とす・ツールバーの「🖼️ 画像」の3通り。
- 貼った画像は長辺1280pxまで縮めてJPEGにしてから保存します。スマホの写真を
  そのまま持つと同期のたびに何MBも往復するためです。
- 画像の実体は端末内のデータベース（IndexedDB）に置き、日記の本文には「どの画像か」
  の目印だけを残します。本文に画像を直接埋めると、6つのアプリで分け合っている
  5MBを一気に食い潰して、日記そのものが保存できなくなるためです。
- 暗号化を有効にしている場合は、画像も同じパスフレーズで暗号化して保存します。
  本文だけ暗号化して画像を素のまま置いたら鍵をかけた意味がないためです。
  暗号化のON/OFFやパスフレーズの変更をすると、保存済みの画像も自動で包み直します。
- どの日記からも使われなくなった画像は自動で片付けます。
- バックアップ（日記帳の書き出し／☁のまとめて書き出す）とDrive同期にも画像を含みます。
  他の端末で開くと画像もついてきます。
- 旧版で本文に直接埋まってしまった画像は、初回起動時に自動で移動します。

■ タグで探せるようになりました
- 「タグで探す」を画面の上のほうに移しました。以前は統計と空のエディタが上を
  占めていて、スマホではタグに届くまで2画面ぶんスクロールが必要でした。
- タグごとの件数を表示し、よく使うタグ（件数の多い順）から並べます。
- タグを選ぶと自動でリスト表示に切り替わり、結果まで移動します。
- 複数選んだときは「どれか含む／すべて含む」を切り替えられます。
- タグが10個を超えると、タグ名で絞り込む入力欄が出ます。
- 一覧の各項目にタグを表示します。押すとそのタグで絞り込めます。
- 画像のある日記には 🖼️ が付きます。
- 統計はいちばん下に移し、折りたためるようにしました。

【v24 での追加（日記帳）】

■ リンクに表示名を付けられるようになりました
- ツールバーの「リンク」で、表示するテキストとURLを別々に入れられます。
  以前はURLだけを聞いて、長いURLがそのまま本文に並んでいました。
- 文字を選んでからボタンを押すと、その文字が表示テキストの初期値に入ります。
- URLは「example.com/abc」のようにスキームを省いても https:// を補います。
- 本文のリンクを押すと編集ダイアログが開きます（表示名の変更・リンクを外す）。
- URLをそのまま貼り付けるとリンクになります。文字を選んだ状態で貼ると、
  その文字がリンクの見出しになります。
- 使えるのは http(s): / mailto: / tel: だけです。javascript: などは弾きます。

■ 画像の入れ方（3通り）
- コピーして貼り付け（スマホの写真アプリからコピー →本文で貼り付け）
- 写真をドラッグして本文に落とす
- ツールバーの「🖼️ 画像」から選ぶ（スマホでは写真アプリが開きます）
※ どの入れ方でも、長辺1280pxのJPEGに自動変換してから保存します。
  実測では 2400x1600 のPNG(127KB) が 17KB になりました。スマホの写真なら
  数MB → 200KB前後です。透過画像は白地を敷いてから変換します。

【v25 での修正（日記帳の画像）】

■ 貼れる形式
- JPEG / PNG / GIF / WebP / AVIF / BMP など、ブラウザが表示できる画像はすべて。
  WebPもそのまま貼れます（保存時にJPEGへ変換されます）。
- 貼れないもの:
    HEIC / HEIF …… iPhoneの写真そのままの形式。ブラウザが開けません。
                    写真アプリの共有から「ファイルに保存」でJPEGにするか、
                    ツールバーの🖼️画像から選び直してください（多くの端末では
                    このとき自動でJPEGに変換されます）。
    TIFF ……………… ブラウザが開けません。JPEGかPNGにしてください。

■ 変換のきまり
- 長辺1280pxまで縮小 → JPEG（品質0.72）で保存します。
  実測: 2000x1200のWebP → 9KB / 2400x1600のPNG(127KB) → 17KB
- 透過している画像は、白地を敷いてから変換します（黒く潰れないように）。
- 動くGIFは変換しません（2MBまではそのまま保存）。変換すると1コマ目の
  静止画になってしまうためです。

■ 失敗したときに必ず理由が出るようにしました
- 以前は「画像を取り込んでいます…」と出たまま、貼れなくても何も言いませんでした。
  いまは必ず結果まで伝えます。理由も分けて出します:
    ・HEIC形式です → 変換方法を案内
    ・TIFF形式です
    ・形式が開けない／ファイルが壊れている
    ・変換に失敗した（画像が大きすぎる）
    ・端末の保存容量が足りない
    ・画像ファイルではない
- 失敗の通知は読み終わるまで消えません（押すと消せます）。
