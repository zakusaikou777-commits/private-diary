Googleドライブで同期（PC・スマホで揃える）

クライアントIDは4つのアプリで共通です。ここで一度だけ設定すれば、日記帳・気になり帳・暗室・音のすべてで使われます。

ファイルに保存（Googleを使わない場合）

4つのアプリのデータ（添付の画像・ファイルも含む）を1つのファイルに書き出し／取り込みします。取り込むと現在のデータは置き換わり、自動で再読み込みします。

セキュリティ
🔐 日記の暗号化—

暗号化されるのは日記帳だけです。気になり帳・暗室・音は平文のまま保存されます。パスフレーズを忘れると日記は復元できないので、必要かどうかは設定画面の説明を読んでからお決めください。

❓ ヘルプ・設定ガイド

日記帳・気になり帳・暗室・音（BGM）の4-in-1アプリです。データはこの端末（各アプリ内）に保存されます。GoogleドライブやGoogleカレンダーと連携するときは、最初に少しだけ設定が必要です。

暗室（イメージストリーミング）

🎞️ 暗室タブは、情景を思い浮かべて五感の細部を声に出して描写する練習（ウェンガー式イメージストリーミング）のためのタイマーと記録です。情景のお題・3/5/10分タイマー・音声ガイド・Ten/Ten（10分×10日）の進捗が使えます。練習記録はこの端末に保存され、上部の ☁ から同期・バックアップできます。

音（BGM）

🎧 音タブは、YouTubeのBGMを毎回探さずに呼び出すためのものです。ジャンルから検索して、気に入った動画のURLを登録しておくと、次回はタップだけで再生できます。お気に入り（★）と再生履歴が残り、スリープタイマー・連続再生・シャッフルが使えます。

  • 他のタブに切り替えても鳴り続けます（このアプリを開いている間）。日記を書きながらBGMを流せます。
  • スマホで画面を消すとYouTubeは止まります。これはブラウザ側の仕様で、回避できません（iPhoneのSafariも同じ）。💡ボタンで「画面を消さない」を有効にすると消灯を防げますが、電池を多く使います。
  • 「就寝用の音」（ブラウンノイズ・ピンクノイズ・雨）は端末内の音なので、画面を消しても鳴り続けます。寝るときはこちらをお使いください。
  • 埋め込み再生を禁止している動画があります。その場合は「↗ YouTubeで開く」に切り替わります。
  • Androidでは、YouTubeアプリの「共有」からこのアプリに送ると、音タブに直接登録されます。

連携を使う前の準備（共通・最初の1回だけ）

ドライブ／カレンダーはあなたのGoogle認証（クライアントID）を使うため、Google Cloud側の設定が必要です。すでにドライブ保存が使えているなら、カレンダー用に「Calendar APIの有効化」と「スコープ追加」を足すだけです。

  • ① httpsで公開：このアプリは https:// のURLで開く必要があります（file:// やローカルだとログイン・カレンダー・通知が動きません）。そのURLのオリジンを③で登録します。
  • ② APIを有効化：Google Cloud Console →「APIとサービス」→「ライブラリ」で Google Drive API と Google Calendar API をそれぞれ有効化。
  • ③ JavaScript生成元を登録：「APIとサービス」→「認証情報」→ ウェブ用のOAuthクライアントIDを開き、承認済みのJavaScript生成元 に、このアプリを開くURLのオリジン（例 https://yourname.github.io）を追加。パスは不要、オリジンだけ。保存後、反映に数分かかることがあります。
  • ④ OAuth同意画面：公開ステータスが「テスト」ならテストユーザーに自分のGoogleアカウントを追加。スコープに drive.file drive.appdata calendar.events を含めます。

Googleカレンダー連携（気になり帳）

  • メモに日付（任意で時刻）を入れると、カードに「カレンダーに登録」が出ます。押すとGoogleカレンダーに予定を作成します。
  • 登録後は「更新」（メモを直したら予定に反映）「解除」（カレンダーから削除）が出ます。
  • ヘッダーの 📅 で「今後の予定」を表示（読み取り専用）。
  • 気になり帳→Googleの片方向です。メモを削除しても予定は自動で消えません（先に「解除」を）。

Googleドライブ バックアップ

  • 気になり帳：ヘッダーの同期アイコンから、ドライブに保存／読み込み（自動同期も可）。
  • 日記帳：日記の設定からドライブに保存。
  • 端末をまたいでデータを引き継げます。
  • 上部の ☁ がデータの同期・バックアップ・セキュリティのすべての入口です。日記帳の中にあった「エクスポート」「セキュリティ」ボタンは、ここから開くようになりました。4つのアプリの同期状態がこの1画面で確認でき、「今すぐ全部同期」でまとめて実行できます。Googleを使わないファイルへの書き出し／取り込み（画像も含む）も同じ画面にあります。クライアントIDは4アプリ共通なので、設定は一度だけです。

うまくいかないとき

  • 403 / forbidden：APIが未有効化、またはスコープ未追加。準備②④を確認。
  • 401 / ログインを求められる：もう一度サインイン。
  • origin / redirect エラー：「承認済みのJavaScript生成元」に今のURLのオリジンが入っているか（httpsか、ポート違いはないか）を確認。
  • ポップアップが出ない：ブラウザのポップアップブロックを許可。
  • 反映されない：Cloud設定の変更直後は数分待つ／シークレットウィンドウで再試行。
  • スマホで保存したい：AndroidはこのアプリをChromeの「ホーム画面に追加」でインストールすると、各アプリの共有メニューから気になり帳に保存できます。iPhoneや拡張なしのPCはクリッパーのページのブックマークレットが使えます。
  • 別の端末でメモが見えない：データは端末・ブラウザごとに別保存です。気になり帳のDrive自動同期を両方の端末でONにしてください。
  • 通知が来ない：ブラウザの制限により、リマインド通知はアプリ（タブ）を開いている間にお知らせします。タブを閉じた状態での時刻指定通知は、現在の主要ブラウザでは未対応です（iPhoneのSafariも同様）。

上級者向け：別のクライアントIDを使う場合は、アプリ内のIDの置き換え（コード編集）が必要です。
