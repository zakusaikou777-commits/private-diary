気になり帳クリッパー（Chrome拡張）  version 1.2.1

【入れ方】
1) Chromeで chrome://extensions を開く
2) 右上「デベロッパーモード」をオン
3)「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択
4) ツールバーの「気」アイコン → ⚙（歯車）に、自分の kininari.html のURL（https）を入力
   例: https://yourname.github.io/app/kininari.html
   ※ 社内やローカルのサーバーなら http:// でも動きます。
5) 同じ⚙の中の「保存の確認を許可する」を押しておくと、保存できたかを確かめられます（任意・下記）
6) 以降、保存したいページで「気」アイコン → 内容を確認して「保存」

【権限について】
- activeTab / scripting … 見ているページのタイトル・選択テキスト・OG画像を読むため
- storage …………………… 保存先URLと既定の分類、直近の保存結果を覚えるため。あわせて
                              「いま処理中の裏タブのURL」も一時的に控えます（ブラウザを
                              閉じたときの取り残しを次の起動で片付けるため。片付いた
                              時点で消します）
- alarms ………………………… 裏で開いたタブを必ず閉じるため（Chromeが拡張を休ませても
                              取り残しを点検して片付けます）
- （任意）保存先サイトへのアクセス
    ⚙（設定）の「保存の確認を許可する」を押したときだけ確認が出ます。許可すると、
    裏で開いたタブで保存が終わったのを確かめてから閉じるので、回線が遅いときの
    取りこぼしに気づけます。許可しない場合も保存は動きますが（一定時間待ってから
    閉じます）、保存できたかどうかは確認できないため、ポップアップも
    「保存先を開きました（保存できたかは未確認）」としか言いません。

【保存の結果の見え方】
ポップアップは閉じるのが早いので、結果はツールバーのアイコンのバッジにも出ます。
  ✓（緑）… 保存を確認できた
  !（赤）… 保存できなかった／確認できなかった（アイコンにマウスを乗せると理由が出ます）
バッジは次にポップアップを開くと消え、うまくいかなかった場合はその理由が文章で出ます。
裏で開いたタブを保存が終わる前に手で閉じると、保存できたかどうかは分からなくなるので
「保存先のタブが閉じられたため、保存できたか分かりません」と出ます（!（赤））。
ブラウザを閉じたときに処理中だったタブは、次にChromeを起動したときに探して片付けます
（「保存の確認を許可する」を押していない場合は、タブのURLを読めないため探せません）。

【メモの長さについて】
選択テキストは先頭2000文字までを取り込みます。URL全体が長くなりすぎる場合は、
送る前に画像やメモを削ります（削ったときはポップアップに出ます）。

いずれの権限も、見ているページの内容を外部へ送ることはありません。保存先は
あなたが設定した自分の気になり帳のURLだけです。

【配布用ZIPの作り直し】
clipper.html に埋め込んでいる配布ZIPは、このフォルダから作り直せます。
  python3 .tools/build-clipper.py
（/tmp/work で実行。ZIPの中身と clipper.html に表示するバージョン番号を、
  このフォルダの manifest.json に合わせて更新します）
