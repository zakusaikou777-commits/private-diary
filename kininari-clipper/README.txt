気になり帳クリッパー（Chrome拡張）  version 1.3.0

【入れ方】
1) Chromeで chrome://extensions を開く
2) 右上「デベロッパーモード」をオン
3)「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択
4) ツールバーの「気」アイコン → ⚙（歯車）に、自分の kininari.html のURL（https）を入力
   例: https://yourname.github.io/app/kininari.html
   ※ 社内やローカルのサーバーなら http:// でも動きます。GitHub Pages などは http:// で
      開くと https:// へ転送されるので、必ず https:// のURLを入れてください。
5) 同じ⚙の中の「保存の確認を許可する」を押しておくと、保存できたかを確かめられます（任意・下記）
6) 以降、保存したいページで「気」アイコン → 内容を確認して「保存」

【権限について】
- activeTab / scripting … 見ているページのタイトル・選択テキスト・OG画像を読むため
- storage …………………… 保存先URLと既定の分類、直近の保存結果を覚えるため。あわせて
                              「いま処理中の裏タブのURL」も一時的に控えます（ブラウザを
                              閉じたときの取り残しを次の起動で片付けるため。片付いた
                              時点で消します）
- alarms ………………………… 裏で開いたタブを必ず閉じるため（Chromeが拡張を休ませても
                              取り残しを点検して片付けます）
- （任意）保存先サイトへのアクセス
    ⚙（設定）の「保存の確認を許可する」を押したときだけ確認が出ます。許可すると、
    裏で開いたタブで保存が終わったのを確かめてから閉じるので、回線が遅いときの
    取りこぼしに気づけます。許可しない場合も保存は動きますが（一定時間待ってから
    閉じます）、保存できたかどうかは確認できないため、ポップアップも
    「保存先を開きました（保存できたかは未確認）」としか言いません。
    保存先URLが http:// の場合（社内・ローカル以外）は、転送先の https:// 側も
    あわせて求めます。それでも別のアドレスへ転送されて確かめられなかったときは、
    ポップアップに保存先URLの直し方が出ます。
- （任意）閲覧履歴
    上と同じ「保存の確認を許可する」のときに一緒に求めます。裏で開いた保存用の
    URL（#knadd= のあとにクリップの中身が入っています）を、閉じたあとで閲覧履歴
    から消すためだけに使います。ほかの履歴は消しません（保存した前後の履歴から、
    同じ保存の番号 kn_clip が付いたURLだけを探して消します）。許可しなくても
    保存は動きますが、その場合は保存用のURLが履歴に残ります。
    ※ 1.2 までに「保存の確認を許可する」を押していた場合は、ボタンが
      「履歴からの消去も許可する」になるので、押すと履歴の分だけ追加できます。

【保存の結果の見え方】
ポップアップは閉じるのが早いので、結果はツールバーのアイコンのバッジにも出ます。
  ✓（緑）… 保存を確認できた（「もう保存してありました」も同じ✓。二重には入れません）
  !（赤）… 保存できなかった／確認できなかった（アイコンにマウスを乗せると理由が出ます）
バッジは次にポップアップを開くと消え、うまくいかなかった場合はその理由が文章で出ます。
気になり帳の容量がいっぱいのときや、受け取れない形式だったときは、待たずにすぐ
その旨が出ます。
1回の保存ごとに番号（URLの kn_clip）を付けて送るので、同じポップアップで保存を
押し直しても、気になり帳には二重に入りません（「もう保存してありました」と出ます）。
裏で開いたタブを保存が終わる前に手で閉じると、保存できたかどうかは分からなくなるので
「保存先のタブが閉じられたため、保存できたか分かりません」と出ます（!（赤））。
裏のタブは、シークレットウィンドウから保存したときも通常のウィンドウに開きます
（シークレットの中に保存すると、ウィンドウを閉じたときに消えてしまうため）。
ブラウザを閉じたときに処理中だったタブは、次にChromeを起動したときに番号で探して
片付けます（「保存の確認を許可する」を押していない場合は、タブのURLを読めないため
探せません）。

【メモの長さについて】
選択テキストは先頭2000文字までを取り込みます。URL全体が長くなりすぎる場合
（約32000文字。日本語は送るときに約9倍の長さになります）は、送る前に画像や
メモを削ります（削ったときはポップアップに出ます）。

いずれの権限も、見ているページの内容を外部へ送ることはありません。保存先は
あなたが設定した自分の気になり帳のURLだけです。

【配布用ZIPの作り直し】
clipper.html に埋め込んでいる配布ZIPは、このフォルダから作り直せます。
  python3 .tools/build-clipper.py
（リポジトリの直下で実行。ZIPの中身と clipper.html に表示するバージョン番号を、
  このフォルダの manifest.json に合わせて更新します。ZIPは解凍すると
  kininari-clipper フォルダができる形で、何度作っても同じ中身になります）
